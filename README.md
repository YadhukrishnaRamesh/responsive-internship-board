# InternshipHub — Responsive Internship Board

A responsive, accessible internship listing interface built with **HTML, CSS, and vanilla JavaScript** (no frontend framework).

## Features

- Responsive layout for mobile, tablet, and desktop
- Reusable internship data records rendered into cards
- Live keyword search across role, company, domain, work mode, and description
- Domain and work-mode filters
- Reset and clear-search controls
- Helpful empty-result state and error fallback
- Semantic HTML, accessible form labels, skip link, keyboard focus styles, and reduced-motion support
- Mobile navigation menu
- Twelve clearly labelled **sample/demo** internship records

## Run locally

1. Download and extract the ZIP, or clone the repository.
2. Open `index.html` in a modern browser.
3. Try searching for `Python`, `remote`, `design`, or `AI`.
4. Test the domain and work-mode dropdowns, then try a search with no matches.
5. Resize the browser or test the page on a phone.

No package installation, build process, or server is required.

## Files

- `index.html` — semantic page structure and form controls
- `style.css` — design system, cards, responsive breakpoints, and accessibility styles
- `script.js` — sample data, filtering, rendering, and UI interactions

## Publish using GitHub Pages

1. Create a public GitHub repository named `responsive-internship-board`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Open the generated public URL and test it.
7. Submit that public URL in the internship portal.

## Important note

This is a portfolio/demo board. The companies and listings are sample records and are not verified vacancies. The enquiry links use a placeholder email address (`careers@example.com`); replace them with verified application links if you later use real listings.
